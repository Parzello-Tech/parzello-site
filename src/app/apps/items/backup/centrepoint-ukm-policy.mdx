## Overview

**Centrepoint** adalah produk utama dari program Digitalisasi UKM POLICY. Aplikasi ini menggantikan sistem absensi manual dengan solusi digital yang dapat diakses seluruh anggota melalui smartphone.

## Key Features

-   **Digital Attendance**: Absensi via scan QR code atau lokasi GPS (Geofencing).
-   **Member Directory**: Daftar anggota aktif beserta jabatan struktural.
-   **Event Management**: Jadwal rapat, workshop, dan agenda organisasi.
-   **Announcements**: Notifikasi push untuk berita penting.

## Tech Stack

-   **Flutter** untuk aplikasi Android & iOS.
-   **Cloud Firestore** untuk database real-time absensi.
-   **Firebase Cloud Messaging** untuk push notification.

## Impact

Sejak diluncurkan, Centrepoint meningkatkan kedisiplinan anggota dan mempermudah pengurus mengevaluasi keaktifan secara transparan dan terukur.
