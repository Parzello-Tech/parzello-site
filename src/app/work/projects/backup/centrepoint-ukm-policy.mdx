## Overview

**Centrepoint** adalah produk utama dari program Digitalisasi UKM POLICY. Aplikasi ini menggantikan sistem absensi manual yang tidak efisien dengan solusi digital yang dapat diakses oleh seluruh anggota melalui smartphone masing-masing.

## Key Features

-   **Digital Attendance**: Absensi menggunakan scan QR code atau lokasi GPS (Geofencing).
-   **Member Directory**: Daftar anggota aktif beserta profil dan jabatan struktural mereka.
-   **Event Management**: Fitur untuk melihat jadwal rapat, workshop, dan agenda UKM lainnya.
-   **Announcements**: Notifikasi push untuk berita penting organisasi.

## Technologies Used

-   **Flutter**: Framework lintas platform untuk Android dan iOS.
-   **Firebase Cloud Messaging**: Untuk fitur push notifications.
-   **Cloud Firestore**: Database real-time untuk mencatat kehadiran.
-   **Firebase Storage**: Digunakan untuk menyimpan file profil anggota.

## Impact

Sejak diluncurkan, Centrepoint telah meningkatkan kedisiplinan anggota UKM POLICY dan mempermudah pengurus dalam mengevaluasi keaktifan anggota secara transparan dan terukur.
