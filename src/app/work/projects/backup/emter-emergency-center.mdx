## Overview

**EMTER (Emergency Center)** adalah aplikasi yang dirancang untuk mempercepat koordinasi bantuan saat terjadi situasi darurat seperti kecelakaan, bencana, atau kejadian medis mendadak. Fokus utamanya adalah menghubungkan korban dengan pihak berwenang secepat mungkin.

## Key Features

-   **SOS Button**: Sekali tekan untuk mengirimkan koordinat lokasi ke pusat kendali.
-   **Real-time Chat**: Komunikasi langsung dengan operator darurat.
-   **Interactive Map**: Menampilkan lokasi pos bantuan terdekat (Police, Hospital, Fire Station).
-   **Contact Sync**: Fitur "Emergency Contacts" untuk memberi tahu keluarga secara otomatis.

## Technologies Used

-   **Flutter**: Framework aplikasi mobile yang responsif.
-   **Google Maps API**: Untuk integrasi pemetaan dan pelacakan lokasi.
-   **Firebase Realtime Database**: Untuk pengiriman pesan chat instan.
-   **Cloud Messaging**: Untuk pemberitahuan kondisi darurat.

## Vision

EMTER memiliki misi untuk menjadi platform standar dalam penanganan keadaan darurat, sehingga setiap orang merasa lebih aman dengan dukungan teknologi di saku mereka.
