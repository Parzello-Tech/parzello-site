## Overview

Sebagai bagian dari inisiatif digitalisasi, UKM POLICY membutuhkan kehadiran online yang profesional. Website ini berfungsi sebagai wajah organisasi di dunia digital, menampilkan profil UKM, dokumentasi kegiatan, dan artikel seputar teknologi Open Source.

## Key Features

-   **Dynamic Blog**: Pengurus dapat mengunggah artikel dan tutorial Linux secara mandiri.
-   **Resource Center**: Halaman khusus untuk mengunduh modul pelatihan dan software bermanfaat.
-   **Responsive Layout**: Desain yang menyesuaikan dengan perangkat mobile maupun desktop.
-   **Contact Integration**: Formulir terintegrasi bagi mahasiswa yang ingin bergabung atau bertanya seputar UKM.

## Technologies Used

-   **PHP & MySQL**: Sebagai basis aplikasi web yang dinamis.
-   **HTML, CSS, & JS**: Untuk pembangunan kerangka dan animasi antarmuka.
-   **Bootstrap**: Framework CSS yang digunakan untuk memastikan responsivitas desain.

## Outcome

Website UKM-POLICY berhasil meningkatkan visibilitas organisasi di tingkat kampus dan memudahkan proses pendaftaran anggota baru secara online.
